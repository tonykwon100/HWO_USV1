# 자율주행 수상드론(USV/ASV) — 6개 전문가 관점 딥리서치

작성일: 2026-07-02 · 각 주장에 출처 병기 · 출처 간 불일치는 그대로 병기 · 단일 출처 의존 주장은 `[단일출처]` 표시

---

## 관점을 관통하는 3줄 요약

1. **기술은 "위치추정·경로제어"가 아니라 "다른 곳"에서 막힌다.** 항법 AI는 데모 수준에서 잘 돌아가지만, 실전 병목은 기계·전기 신뢰성, 무승선 정비 공백, 통신 의존성, COLREGs 알고리즘의 체계적 실패, 규제 공백으로 이동했다.
2. **"완전 무인 자율"은 2026년 현재 실증 사례가 없다.** 실제 결과는 유인 감독(Yara Birkeland), 98% 자율·2% 개입(Suzaku), 절반만 자율(PRISM Courage), 기계 고장 중단(Mayflower)이며, 무인화는 대체로 인간을 배에서 육상 원격운영센터(ROC)로 "옮긴 것"에 가깝다.
3. **돈과 제도가 궤도를 정한다.** 투자·예산은 압도적으로 방위에 쏠려 있고(우크라이나 비용 비대칭이 핵심 동력), 합법 운항의 경계는 국제법이 아니라 각국 국내 시험특례 + "인간 선장의 전면 책임 유지" 원칙이 그어준다.

## 1. 실무자(개발자/엔지니어) 관점

**핵심 질문:** 제한된 SWaP 플랫폼에서 GPS 음영·수면 멀티패스·파랑 외란을 견디는 실시간 위치추정과 경로제어를 어떻게 안정적으로 구현하는가?

### 위치추정
- 해양에서 GNSS는 차폐·멀티패스·재밍·태양활동으로 저하된다. INS+DVL(도플러 속도계) 조합은 드리프트를 구속해 1km 구간 0.5m 미만 편차를 보고한 상용 시험이 있다. 다만 DVL은 SWaP상 무겁고 비싸며 소형 USV엔 과할 수 있고, 얕은 수심·기포에서 바닥추적이 끊긴다. 출처: [Unmanned Systems Technology](https://www.unmannedsystemstechnology.com/feature/multi-sensor-maritime-ins-for-resilient-gnss-denied-navigation/), [GPS World](https://www.gpsworld.com/nortek-enables-usv-navigation-in-gnss-denied-environments/)
- EKF로 INS+LiDAR를 통합 후 스테레오 SLAM과 재통합하는 계층적 방식이 GNSS-denied 정밀항법에 쓰인다(원 논문은 UAV/일반 로봇, ASV 이식 가능). 출처: [PMC10490647](https://www.ncbi.nlm.nih.gov/pmc/articles/PMC10490647/), [PMC9786841](https://www.ncbi.nlm.nih.gov/pmc/articles/PMC9786841/)

### 수면 멀티패스 (트레이드오프 병존)
- 가장 흔한 원인은 수면 반사가 안테나 하부로 유입되는 것 → 그라운드 플레인으로 차단 권장. 출처: [VectorNav](https://www.vectornav.com/resources/inertial-navigation-primer/theory-of-operation/theory-gnsscompass)
- **상충하는 트레이드오프:** 듀얼 안테나 GNSS 컴퍼스는 헤딩 정확도(자기 컴퍼스 대비 우수)에 유리하나, 멀티패스에 **더 민감**해 수면·금속 선체 위에서 RTK 고정해를 못 얻을 수 있다. 출처: [VectorNav](https://www.vectornav.com/resources/inertial-navigation-primer/theory-of-operation/theory-gnsscompass)
- 저가 GNSS의 수면 근접 멀티패스 영향은 학계도 "추가 분석 필요"로 명시한 미해결 영역. 출처: [Taylor & Francis](https://www.tandfonline.com/doi/full/10.1080/01490419.2023.2208289)

### 비전/LiDAR SLAM·AprilTag (프로젝트 직접 관련)
- 근안 도킹 시 비전 SLAM은 동적 객체·수면 반사·요동으로 심각한 간섭 → ORB-SLAM3에 해안 세그멘테이션 + 동적 영역 제거를 붙인 개선 SLAM 제안. 출처: [MDPI JMSE 13/4/679](https://www.mdpi.com/2077-1312/13/4/679)
- **AprilTag 도킹의 한계:** 개방 수역에서 하늘/태양광 반사가 마커 일부를 덮어 자세 추정 노이즈 발생. 대안으로 LiDAR SLAM으로 AprilTag 맵을 먼저 구축해 정확 자세를 얻는 접근, 반사 환경용 3D AprilTag 연구. 출처: [Springer](https://link.springer.com/article/10.1007/s41315-021-00193-0), [arXiv 2310.17879](https://arxiv.org/pdf/2310.17879), [arXiv 2001.08622](https://arxiv.org/pdf/2001.08622)

### 파랑 외란 하 경로제어
- **LOS 유도 + 외란관측기(ESO)/동적표면제어(DSC)** 가 임베디드 실배포 관점에서 가장 검증된 선택. 시변 사이드슬립각을 ESO로 식별. 출처: [PMC11359112](https://pmc.ncbi.nlm.nih.gov/articles/PMC11359112/), [Nature s41598-022-05456-9](https://www.nature.com/articles/s41598-022-05456-9)
- 파랑 인지(PM 스펙트럼) + 유한시간 LOS + RBF 신경망 결합 필드 실험. MPC는 매 스텝 QP를 풀어야 해 라즈베리파이급에서 부담(예측지평·모델차수 축소 필요). 출처: [ScienceDirect S0029801826004300](https://www.sciencedirect.com/science/article/abs/pii/S0029801826004300)
- **DRL(강화학습) 제어는 상충·보완 관점:** DDPG/LSTM-TD3가 시뮬레이션에서 빠른 수렴·낮은 오차를 보이나 **대부분 시뮬레이션 위주, 필드 검증 제한적** → PID/LOS 대비 실배포 신뢰성은 미확정. 출처: [S0029801822017322](https://www.sciencedirect.com/science/article/abs/pii/S0029801822017322), [JMSE 14/4/327](https://doi.org/10.3390/jmse14040327)

### ArduPilot/MAVLink·BlueBoat (프로젝트 스택 직접 관련)
- 표준 Rover 펌웨어로 보트 제어(`FRAME_CLASS=2`). Loiter 위치유지, 해수면 GPS 필터링(`GPS_NAVFILTER`), Vectored Thrust 지원. 출처: [ArduPilot Boat Config](https://ardupilot.org/rover/docs/boat-configuration.html)
- MAVLink 하트비트를 `FS_TIMEOUT`초 못 받으면 `FS_ACTION` 페일세이프. 출처: [ArduPilot MAVLink Rover](https://ardupilot.org/dev/docs/mavlink-rover-commands.html)
- **BlueBoat 실사양:** Navigator(RPi4 애드온) + GPS + ArduRover 기본 탑재, 웨이포인트 항법·위치유지·지오펜싱·신호상실 RTL. 듀얼 M200으로 최고 3m/s, 정지추력 8.2kgf, 배터리 확장으로 9시간/30km → 62시간/220km, 페이로드 15kg, 250m WiFi. 출처: [Blue Robotics BlueBoat](https://bluerobotics.com/store/boat/blueboat/blueboat/), [Navigator Setup](https://bluerobotics.com/learn/navigator-hardware-setup/)
- **비-GPS 외부 위치 주입:** MAVLink로 EKF에 외부 위치·속도 주입 가능. 단 EKF3는 위치가 반드시 공급돼야 하며 속도만 주면 타임아웃→페일세이프. `GPS_INPUT`(속도 포함)이 측위에 유리. 소스 스위칭(`RC6_OPTION=90`)으로 GPS↔비전 전환. 출처: [Non-GPS Position](https://ardupilot.org/dev/docs/mavlink-nongps-position-estimation.html), [Issue #23485](https://github.com/ArduPilot/ardupilot/issues/23485)

### 임베디드 실시간성 트레이드오프 (RPi4 독자용)
- **역할 분리가 정석:** EKF3(위치추정)는 FCU(Navigator/Pixhawk)에서, 무거운 SLAM/비전은 컴패니언(RPi)에서 돌려 MAVLink로 posterior만 주입. 출처: [Companion Computers](https://ardupilot.org/dev/docs/companion-computers.html)
- ORB-SLAM3는 RPi5에서 CPU 부하 최고(지역 번들조정·특징매칭), 메모리는 mono-inertial이 stereo보다 ~50% 더 소모, 저해상도에서 파국적 실패 사례. → RPi 단독 실시간은 위험. 출처: [ResearchGate 400559478](https://www.researchgate.net/publication/400559478), [SciELO](https://scielo.org.za/scielo.php?script=sci_arttext&pid=S2313-78352024000200005)
- **경량 대안:** 광류 기반 VIO(KLT/ARM-VO/LEVIO)가 저부하·고프레임 유리(정확도·전역일관성은 열세). LEVIO는 Jetson Nano에서 VINS-Mono 대비 15배 효율. ARM-VO는 RPi3에서 단안 8 FPS. 출처: [arXiv 2602.03294](https://arxiv.org/html/2602.03294v1), [imrid.net](http://imrid.net/?p=4045)
- **주의:** MPC·센서퓨전의 구체적 CPU·전력 벤치마크는 대부분 출처가 미제시(정성적 부담만 확인) → 필요 시 실측 권장.

**실무 결론:** ① EKF3(GPS+INS)를 FCU에, 외부 비전/DVL을 `GPS_INPUT`으로 주입해 GPS 음영 시 무결절 소스 스위칭. ② 수면 반사는 안테나 그라운드 플레인 + 동적 특징점 제거 SLAM. ③ 경로제어는 LOS+ESO/DSC(임베디드 최검증) + PM 스펙트럼 파랑 보강. ④ 무거운 인지는 컴패니언 오프로드 + 경량 VIO 우선.

## 2. 회의론자 관점

**핵심 질문:** 통제된 데모를 걷어내면 개방 수역 무개입 자율운항이 실패하는 지점과 빈도는?

### "무인 자율"이 실제로는 유인 감독
- **Yara Birkeland(하이프 대 현실의 결정판):** "세계 최초 완전 자율" 발표였으나 규제·안전상 승조원 탑승 감독 중(5→3→2명 축소 예정), 접안·계류는 수동. 원격제어 자격을 얻으려면 규제상 2년 승조원 탑승 운항이 요구됨. 출처: [Wikipedia](https://en.wikipedia.org/wiki/MV_Yara_Birkeland), [Yara 공식](https://www.yara.com/knowledge-grows/yara-birkeland-two-years-on/), [ITF](https://www.itfglobal.org/sites/default/files/resources-files/autonomous-ship-yara-birkelnad-how-far-has-the-industry-reached.pdf)
- **Suzaku(MEGURI2040, 일본):** 40시간 항해 중 ~98%만 완전 자율, 2%는 인간 개입 — 그 2%가 폭주 해역·근접 조우 등 가장 어려운 지점. 출처: [Maritime Executive](https://maritime-executive.com/article/japanese-autonomous-navigation-project-moves-to-second-phase-demonstrations), [Nippon Foundation](https://en.nippon-foundation.or.jp/what/projects/ocean/meguri2040)
- **PRISM Courage(Avikus/HD현대):** 대양횡단 2만km 중 절반만 자율. `[단일출처 — 벤더 PR 편향]` 출처: [Interesting Engineering](https://interestingengineering.com/transportation/worlds-first-transoceanic-voyage-autonomous-navigation)

### 기계·전기 신뢰성 실패 (Mayflower)
- IBM/ProMare Mayflower는 2021년 항로 11% 지점에서 추진계 결함으로 회항, 2022년 재시도도 발전기 고장으로 우회해 원목표 도착 실패. **항법 SW는 정상 작동했으나 배 위 정비 인력 부재로 사소한 기계 고장이 임무 중단으로 직결.** Fortune은 "자율선 열풍의 경종"으로 규정. 출처: [The Register](https://www.theregister.com/2022/05/11/mayflower_autonomous_ship/), [Maritime Executive](https://maritime-executive.com/article/mayflower-autonomous-ship-diverts-after-second-mechanical-failure), [Fortune](https://fortune.com/2022/05/17/r2d2-ai-autonomous-ships-malfunction-mayflower-repair/)

### 원격 개입 빈도 — 공개된 유일한 정량치
- **미 해군 대형 USV WESTPAC 배치(2023-24):** 약 2주간 무개입 운용 가능했으나 선원이 안전상 자율시스템을 **13회 비활성화**, 이 중 **6회만 자율성 자체 문제**(나머지는 거친 해상 등). `[핵심 수치, USNI 단일 상세 보도 의존]` 출처: [USNI](https://news.usni.org/2024/01/16/navy-wraps-first-unmanned-surface-deployment-to-westpac), [CRS R45757](https://www.congress.gov/crs-product/R45757)
- **구조적 공백:** 해운에는 자율주행차의 캘리포니아 DMV disengagement report 같은 표준·공개 개입률 지표가 **부재** → "무개입 빈도" 정량화는 대부분 벤더 자기보고 의존.

### 충돌회피(COLREGs) 알고리즘의 체계적 결함 — 가장 견고한 정량 비판
- Reliability Engineering & System Safety(2025): 평가한 **12개 핵심 규칙 중 완전 준수 알고리즘 0개**("critical and systemic failure"), 지리적 제약·선박 우선순위 규칙은 준수율 0, **29개 반복 오류 패턴** 식별. COLREGs 오구현은 성능 저하가 아니라 시스템적 안전 위험. 출처: [ScienceDirect S0951832025010403](https://www.sciencedirect.com/science/article/pii/S0951832025010403), [MDPI 14/24/16516](https://www.mdpi.com/2071-1050/14/24/16516)

### 센서·통신 실패 원인
- 레이더 해상 클러터가 오탐/미탐을 동시 유발, 임계값 트레이드오프가 근본 제약. 출처: [ION Navi](https://navi.ion.org/content/72/1/navi.687)
- 안개 시 LiDAR 탐지거리 5km 미만, 비 상황 50-100m 중거리 성능 악화(다수 정량치가 자율주행차 문헌 기원 `[도메인 전이 주의]`). 출처: [ScienceDirect S0263224124003579](https://www.sciencedirect.com/science/article/abs/pii/S0263224124003579)
- SATCOM 지연으로 실시간 원격조종이 비현실적 → 사전계획 항로+오토파일럿 의존. 출처: [Unmanned Systems Technology](https://www.unmannedsystemstechnology.com/2021/07/satcom-connectivity-for-autonomous-surface-vessels/)

### 전시 USV 통제상실 (개방 수역 실사례)
- 우크라이나 Magura V5: EW로 통제상실 후 폭발/표류/나포 사례. 출처: [TWZ](https://www.twz.com/ukrainian-drone-boat-appears-to-have-been-captured-by-russia)
- 이란의 미 해군 Saildrone 나포(2022): 무인이라 물리적 저항 불가, 카메라 제거된 채 반환. 출처: [USNI](https://news.usni.org/2022/09/02/iran-temporarily-captures-two-u-s-saildrones-in-red-sea)

**회의론 결론:** 무개입 완전 자율은 미달성. 병목은 자율 AI가 아니라 기계·전기 신뢰성, 정비 부재, 통신 의존, 계류 자동화, 규제 공백으로 이동. 가장 견고한 정량 비판은 COLREGs 알고리즘 실패, 가장 견고한 개입 수치는 미 해군 "2주 13회(6회 자율성 문제)".

## 3. 경제학자(돈의 흐름) 관점

**핵심 질문:** 단위 임무당 비용의 손익분기점은 어디이고, 투자·성장은 어느 응용에 집중되는가?

### 시장 규모·CAGR — 기관별 병렬(평균 내지 않음)
| 기관 | 현재 | 전망 | CAGR | 발행 |
|---|---|---|---|---|
| MarketsandMarkets | $0.82B(2025) | $1.59B(2030) | 14.1% | 2025 |
| Grand View Research | $1.76B(2024) | $3.45B(2030) | 11.9% | 2024 |
| Mordor Intelligence | $1.13B(2025) | $2.18B(2030) | 13.98% | 2025 |
| Fortune Business Insights | $2.4B(2025) | $3.55B(2034) | **4.5%** | 2026 |

## 4. 역사가 관점

**핵심 질문:** 군용 표적함에서 상용 자율운항까지 궤도를 결정한 기술적·제도적 전환점은?

### 타임라인
- **WWI~WWII:** 독일 원격조종 FL-boat, 미 해군 표적드론·소해정 — USV의 직접 기원. 냉전기 내내 "원격조종 표적/소해"에 국한. 출처: [Wikipedia USV](https://en.wikipedia.org/wiki/Unmanned_surface_vehicle), [USNI](https://www.usni.org/magazines/proceedings/2020/june/surprising-history-unmanned-navy-systems)
- **2000-05-01/02:** GPS Selective Availability 해제 → 민간 정밀도 ~100m→20m 이내. 자율항법의 저비용 위치인식 기반. (USV 특정 인과를 명시한 1차 문헌은 미확보 — `[해석적 연결]`, 정밀도 수치는 GPS.gov 공식) 출처: [gps.gov](https://www.gps.gov/selective-availability)
- **2001/2003:** 미 Spartan Scout(ACTD). **2000년대 초:** 이스라엘 Rafael Protector — 최초 실전 운용 전투 USV, 2005년 싱가포르 배치. (초기 언론이 두 프로그램 명칭 혼동 — 별개, 병기). 출처: [Wikipedia Protector](https://en.wikipedia.org/wiki/Protector_USV)
- **2012:** Richard Jenkins가 Saildrone 창립. **2013-10:** SD 1이 순수 풍력으로 대양 횡단(SF→하와이 34일) — 상용·과학 USV의 "대양 데이터수집" 용도 개척. 출처: [Wikipedia Saildrone](https://en.wikipedia.org/wiki/Saildrone_(company))
- **2016:** DARPA ACTUV Sea Hunter 진수("Sparse Supervisory Control"). **2018:** ONR 이관 + Ghost Fleet Overlord 개시. 출처: [Wikipedia Sea Hunter](https://en.wikipedia.org/wiki/Sea_Hunter), [DARPA](https://www.darpa.mil/news/2018/sea-hunter-prototype)
- **2021-06/2022-06:** Mayflower가 대서양 무인 횡단 시도(기계 결함 회항)→재시도로 최초 자율 횡단 달성. 출처: [The Register](https://www.theregister.com/2022/04/29/ibm_autonomous_mayflower/)
- **2017→2021:** IMO MASS 규제 스코핑 연습 착수→MSC 103 완료→목표기반 MASS Code 경로 결론. 출처: [IMO RSE](https://www.imo.org/en/MediaCentre/PressBriefings/pages/MASSRSE2021.aspx)
- **2022~:** 우크라이나 Magura/Sea Baby가 흑해함대를 사실상 무력화 — "해군 없는" 국가가 저비용 소모성 USV로 전략적 유효성 실증 → 글로벌 방산 USV 투자 궤도 재편. (2022-10 세바스토폴 공격 피해함 목록은 출처마다 편차, 병기) 출처: [The Conversation](https://theconversation.com/how-the-ukrainians-with-no-navy-defeated-russias-black-sea-fleet-234259), [Wikipedia MAGURA V5](https://en.wikipedia.org/wiki/MAGURA_V5)

- **불확실:** "MEMS 센서·위성통신이 USV 자율화의 전환점"이라는 명제는 뒷받침 1차 출처 미확보 → 확정 주장에서 제외.

**역사 결론:** 세 물결 — ① 군사적 기원(표적/소해), ② 기술 스택 성숙(GPS 개방·딥러닝), ③ 제도화(IMO MASS 2017~)와 실전 검증(우크라이나 2022~). 우크라이나 전쟁이 최근 궤도를 가장 크게 재조정.

## 5. 최종 사용자(운용자) 관점

**핵심 질문:** 훈련·유지보수·신뢰성 측면에서 실제로 손이 덜 가는가, 새로운 부담을 만드는가?

**결론: 둘 다 참.** 물리적 승선 인력·물류는 줄지만, 부담이 육상 ROC 24/7 감시·위성통신·배터리/정비 사이클·날씨 스케줄링으로 **이전**된다.

### 손이 덜 가는 근거
- 유인 조사선 승선 30~50명 → 전 인력 육상 근무(Van Oord). NOAA 사례에서 USV가 알래스카 조사의 44%를 수집해 커버리지 2배. 출처: [Van Oord](https://www.vanoord.com/en/monitoring-subsea-infrastructure-unmanned-survey-vessels/), [NOAA](https://nauticalcharts.noaa.gov/updates/unmanned-surface-vehicles-evaluated-for-hydrographic-survey/)
- WasteShark: "2인 반나절 → 1인 60분", 부두 in-water 충전. 출처: [RanMarine](https://www.ranmarine.io/wasteshark/)

### 새 부담이 생기는 근거
- 배터리 재충전 수 시간 → 가용성 저하(endurance가 대중화 병목). 출처: [Modern Battlespace](https://modernbattlespace.com/2022/11/02/taking-unmanned-underwater-vehicles-to-the-next-level-of-performance/)
- 위성통신 대역폭 제약이 운용 아키텍처를 규정(XOCEAN은 연산을 선상에 두고 원격제어만). 출처: [R2Sonic/XOCEAN](https://r2sonic.com/case-studies/xocean/)
- 날씨 대기가 사라지지 않고 "스케줄링·다중선박 재배치" 문제로 전환. 출처: [Hydro International](https://www.hydro-international.com/content/article/autonomous-bathymetric-survey-in-the-uk-atlantic)
- WasteShark 바스켓 가득 차면 최대 60kg 수작업 회수 — 완전 무인 아님. 출처: [RanMarine](https://www.ranmarine.io/wasteshark/)

### 훈련·자격
- AUVSI "Trusted UMS Operator", DNV 원격제어 운용자 인증(SeaSkill ST-0324) 형성 중. 미국 FY26 NDAA §7332로 USCG에 훈련요건 수립 지시(진행 중, `[단일출처]`). 소형 수질 USV는 "면허 선장 대신 훈련된 기술자"로 문턱 낮아짐. 출처: [AUVSI](https://www.auvsi.org/news/auvsi-accredits-new-training-providers-under-trusted-ums-operator-program-expanding-maritime-workforce-standards), [DNV](https://smartmaritimenetwork.com/2021/11/29/dnv-starts-certification-for-remote-control-vessel-operators/)

### 신뢰성 데이터
- **정량 MTBF/가동률은 공개 근거에서 미확인** — 사업자는 "world-class uptime"(XOCEAN) 등 정성 마케팅. 학술·방위 문헌은 배터리 지속시간·전압안정성·무승선 정비 공백을 반복 경고. **낙관적 사업자 서사 vs 신중한 기술 문헌 병존.** 출처: [XOCEAN](https://xocean.com/), [MDPI 6/2/17](https://www.mdpi.com/2673-4052/6/2/17)

**사용자 결론:** "인력 감소"가 아니라 "인력 재배치 + 스킬 재정의". 정량 신뢰성 데이터 부족은 실측으로만 해소 가능.

## 6. 규제자(해사 안전·법제) 관점

**핵심 질문:** COLREGs·책임·면허 체계가 무인 자율선박을 전제하지 않는 상황에서 합법 운항의 경계는?

### IMO MASS Code — 최신 정정 (핵심)
- **흔히 인용되는 "2030 채택/2032 발효"는 강제(mandatory) 코드 일정.** 비강제(non-mandatory) MASS Code는 **2026-05-22 MSC 111에서 채택(결의 MSC.595(111)), 2026-07-01 발효**, 화물선 한정 목표기반 프레임워크. 강제 코드는 2028 개발→2030 채택→**2032-01-01 발효 목표**. 출처: [IMO](https://www.imo.org/en/mediacentre/pressbriefings/pages/imo-adopts-mass-code.aspx), [DNV](https://www.dnv.com/news/2026/imo-mcs-111-new-mass-code-adopted/), [MCA/GOV.UK](https://www.gov.uk/government/news/landmark-support-for-shipping-innovation-with-publication-of-maritime-autonomous-surface-ships-mass-code)

### 자율 등급 (IMO 공식, MSC.1/Circ.1638)
- Degree 1: 자동화+선원 승선 / Degree 2: 원격제어+선원 승선 / **Degree 3: 원격제어+선원 미승선** / **Degree 4: 완전자율**. 4단계는 위계가 아니며 한 항해 중 오갈 수 있음. **합법성 논란은 Degree 3·4(선원 미승선)에서 발생.** 출처: [MSC.1/Circ.1638](https://wwwcdn.imo.org/localresources/en/MediaCentre/PressBriefings/Documents/MSC.1-Circ.1638), [DNV](https://www.dnv.com/news/2023/imo-maritime-safety-committee-msc-107--244383/)

### COLREGs 충돌
- **Rule 5 "적절한 경계":** "시각·청각 및 모든 이용 가능한 수단으로" — 1972년 제정 시 인간 감각 전제. 원격운항자가 look-out 자격을 충족하는지가 근본 쟁점(`[단일출처: MDPI 2022]`). 출처: [IMO COLREG](https://www.imo.org/en/about/conventions/pages/colreg.aspx), [MDPI 14/24/16516](https://www.mdpi.com/2071-1050/14/24/16516)
- **Rule 2 "good seamanship":** 모호해 기계 판독형 변환이 어렵고, ML이 위반 섞인 항적으로 학습되면 위반을 학습("garbage in, garbage out"). 
- **관점 상충(사실 충돌 아님):** 학술(MDPI)은 Rule 5/2가 무인선에 근본 부적합이라는 회의론, IMO·로펌 HFW는 개정으로 해결 가능하다는 실무론. 출처: [HFW](https://www.hfw.com/insights/autonomous-ships-mass-mutations-feb-2021/)

### seafarer/master 정의·책임
- IMO(MSC 107, 2023): 원격운영센터 운항자가 미승선이면 **STCW가 적용되지 않음** — 규제 공백. 출처: [MarineLink](https://www.marinelink.com/news/imo-agrees-relevance-stcw-autonomous-505799)
- 책임: 현행 충돌책임은 과실 기반이라 무인선에 그대로 적용 곤란, 책임이 선주→제조사·SW 개발자로 이동(경계 불분명), 무과실책임 전환론 제기. **IMO 원칙: 인간 선장이 승선 여부와 무관하게 전면 책임 보유 + 개입 수단 보유(기능적 동등성).** CMI가 LEG 111(2024)에 논문 제출했으나 심층검토는 MASS Code 완성 후로 유예. 출처: [Wiersholm](https://wiersholm.no/en/newsletter/liability-for-damage-caused-by-autonomous-ships-a-norwegian-perspective), [HFW](https://www.hfw.com/insights/autonomous-ships-drawing-a-line-in-the-sand/), [CMI](https://comitemaritime.org/cmi-submission-on-cmi-paper-on-issues-concerning-mass-liability-to-leg-111/)

### 국가별 (소형 USV에 특히 중요)
- **영국 MCA(최정교):** 길이별 3단계 — <2.5m MGN 702 일반면제(2024-08), 2.5~4.5m MGN 705, 4.5~24m Workboat Code Edition 3(무인선 최초 명시 포함, 2023-12). 출처: [MGN 702](https://www.gov.uk/government/publications/mgn-702-m-), [Haynes Boone](https://www.haynesboone.com/news/publications/new-workboat-code-includes-remotely-operated-unmanned-vessels-for-first-time)
- **노르웨이:** Trondheim 피오르드 = 세계 최초 자율선 시험구역(2016). 출처: [Sjøfartsdirektoratet](https://www.sdir.no/en/news/worlds-first-test-area-for-autonomous-ships-opened/)
- **미국 USCG:** 별도법 대신 기존 항법규칙+사안별 평가+CRADA. 최소 승무 요건이 무인화 재량 제한(GAO 지적). 출처: [GAO-24-107059](https://www.gao.gov/assets/gao-24-107059.pdf)

### 소형 USV 사각지대
- SOLAS는 500 GT 미만 화물선을 제외 → 소형 USV 대부분 국제협약 밖(`[단일출처]`). UNCLOS는 "ship"을 명시 정의하지 않아 소형 무인정 지위 불확실. 군용 USV 주권면제는 광의설 vs 협의설 정면 상충. 출처: [CIMSEC](https://cimsec.org/unmanned-maritime-systems-and-warships-interpretations-under-the-law-of-the-sea/), [USNI](https://www.usni.org/magazines/proceedings/2024/february/collision-regulations-need-be-updated-usvs)

**규제 결론:** 합법 운항 경계는 국제법이 아니라 **"기국·연안국 국내 특례 승인 + 인간 선장의 전면 책임 유지"** 로 그어진다. 새 MASS Code조차 비강제·화물선 한정이라 강제력은 2032년까지 유예. 소형 USV는 톤수·길이 임계값 아래라 국제협약 사각지대에 있어, 국내 특례가 유일한 합법 근거이자 동시에 공백.
