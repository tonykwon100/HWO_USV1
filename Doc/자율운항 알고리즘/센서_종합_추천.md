# 수상 드론 자율 주행 — 센서 종합 추천

> 대상 플랫폼: BlueRobotics BlueBoat  
> 운용 환경: 실내 수조 (300m × 16m)  
> 목적: 수면 부유물(기름, 철가루 등) 자동 수집  
> 작성일: 2026-05-10  

---

## 1. 센서 구성 개요

자율 주행에 필요한 3가지 센서 역할 분담:

| 센서 | 주요 역할 | 보조 역할 |
|------|-----------|-----------|
| **LiDAR** | 장애물 탐지, 벽면 거리 측정 | 2D 맵 구성 |
| **초음파** | 4방향 근거리 장애물 감지 | 벽면 추종 |
| **카메라** | AprilTag 절대 위치 보정 | 부유물 탐지 |

센서 퓨전 흐름:

```
LiDAR (2D map + 장애물)
        ↓
초음파 (근거리 4방향)   →  EKF 퓨전  →  위치/방향 추정  →  경로 계획  →  차동 추력 제어
        ↓
카메라 + AprilTag (절대 위치 앵커)
        ↓
Navigator IMU + Compass
```

## 2. LiDAR 추천

### 최종 추천: RPLIDAR S2

| 항목 | 사양 |
|------|------|
| **측정 거리** | 최대 30m |
| **스캔 속도** | 10Hz |
| **각도 분해능** | 0.08° |
| **스캔 범위** | 360° |
| **인터페이스** | UART / USB |
| **가격** | ~$200 (USD) |

**선택 이유:**
- 수조 300m × 16m → 단변 16m 커버에 30m 측정거리로 충분한 여유
- ROS2 드라이버 기본 제공, RPi4 / Jetson 즉시 연동
- 스캔 포인트: 10Hz × 360° / 0.08° = **4,500 포인트/scan** → Jetson Nano급에서 실시간 처리 가능
- 가성비 최고 (동급 대비)

**단점 및 대응:**
- IP 등급 없음 → **방수 케이스 별도 제작 필수** (수면 splash 대응)
- 수면 반사광 false positive 가능 → 라이더는 벽면/장애물 탐지 전용으로 사용하고 **부유물 탐지는 카메라 CV로 처리**

**대안: Leishen LS-01B (~$300)**
- IP54 자체 방수, 한국 대리점 A/S 가능
- 실외·스플래시 환경 우선 시 선택

**성능/메모리 트레이드오프:**
- RPi4에서 15Hz 이상 처리 시 병목 → **Jetson Nano 이상 권장**
- PointCloud 버퍼: 4,500 포인트 × 4바이트(float) × 2(x,y) = ~36KB/scan → 메모리 부담 없음

## 3. 초음파 센서 추천

### 최종 추천: DFRobot URM06 RS485 (SEN0149)

| 항목 | 사양 |
|------|------|
| **측정 거리** | 0.2m ~ 10m |
| **화각** | 15° |
| **인터페이스** | RS485 (Modbus RTU) |
| **전원** | 6V ~ 12V |
| **분해능** | 1cm |
| **가격** | ~$35 ~ $45 (USD) |

**선택 이유:**
- RS485 Modbus: 1개 UART 포트로 **최대 32개 센서 멀티드롭** → 4방향 구성에 배선 단순화
- 10m 측정 거리로 요구사항 충족
- 15° 화각: 좁아서 오탐 적고, 2개 전방 배치(30° 커버)로 충분
- DFRobot 공식 문서·예제 풍부

**권장 배치 (4방향 + 하향 1개):**

```
       [전방 URM06 × 2]  ← 15° × 2 = 30° 커버
드론 ── [좌측 URM06 × 1]
       [우측 URM06 × 1]
       [후방 URM06 × 1]
       [하향 KS109  × 1] ← 부유물 정밀 위치 파악용
```

**단점 및 대응:**
- 자체 방수 미지원 → **IP65 이상 인클로저 + 초음파 투과창(실리콘 씰링)** 별도 제작
- 수면 반사 오측 가능 → 센서 마운트 **5~10° 하향 틸트** 권장

**보조 센서: Taidacent KS109 RS485 (~$60)**
- 화각 10°, 1mm 분해능, 온도 보상 내장
- 하향 마운트 시 부유물 정밀 거리 측정에 적합

**성능/메모리 트레이드오프:**
- RS485 Modbus RTU 폴링: 5개 센서 × 10Hz = 50회/초 → MCU(예: STM32) 처리 후 UART로 RPi에 전달 권장

## 4. 카메라 추천

### 역할 구분

카메라는 2가지 용도로 구분하여 운용:

| 용도 | 설명 |
|------|------|
| **위치 보정** | AprilTag 검출 → 절대 위치 보정 (코너·벽면 마커) |
| **부유물 탐지** | 하향 카메라로 수면 CV 분석 |

---

### 4-1. 위치 보정용 (AprilTag 전방 카메라)

#### 최종 추천: Raspberry Pi Camera Module 3 Wide

| 항목 | 사양 |
|------|------|
| **센서** | Sony IMX708 (12.3MP) |
| **FOV** | 102° (대각) |
| **오토포커스** | Phase Detection AF |
| **인터페이스** | CSI (RPi 전용) |
| **HDR** | 지원 |
| **가격** | ~$35 (USD) |

**선택 이유:**
- BlueBoat 온보드 RPi4와 **CSI 직결, CPU 부하 최소화** (USB 대비 15~20% 절감)
- 102° FOV → 좁은 수조 코너에서 마커 검출 범위 충분
- Phase Detection AF → 드론 이동 중 마커 초점 자동 유지
- 드라이버 별도 설치 불필요, libcamera 기본 지원

**단점:**
- 롤링 셔터 → 고속 이동 시 마커 검출률 저하 가능
  - 대응: `quad_decimate=2.0` + 60fps 720p 모드로 모션 블러 최소화

**대안: Arducam IMX477 Global Shutter Module (~$70)**
- 글로벌 셔터 → 드론 진동·이동 중 마커 왜곡 없음
- 수면 파도로 인한 드론 요동이 심한 경우 우선 선택
- 오토포커스 없음 → 마커 거리 고정(2~5m) 시 수동 초점 설정

**AprilTag 설정 권장값:**

```python
detector = Detector(
    families='tag36h11',  # 오탐 최저, 수상드론 표준
    nthreads=4,
    quad_decimate=2.0,    # 720p 기준 ~20fps 달성
    refine_edges=1,
)
# 태그 크기 권장: 20cm (3m 이내 검출), 50cm (7m 이내 검출)
```

---

### 4-2. 부유물 탐지용 (하향 카메라)

#### 최종 추천: Raspberry Pi Camera Module 3

| 항목 | 사양 |
|------|------|
| **센서** | Sony IMX708 (12.3MP) |
| **FOV** | 66° (대각) |
| **오토포커스** | Phase Detection AF |
| **인터페이스** | CSI |
| **가격** | ~$25 (USD) |

**선택 이유:**
- 하향 장착 시 66° FOV → 수면과의 거리(0.3~0.5m)에서 적정 커버리지
- RPi Camera Module 3 Wide와 동일 드라이버 → 2대 동시 운용 가능 (RPi5는 CSI 2포트)
- 부유물 CV 분석: 기름막 색상 검출(HSV 필터), 철가루 반사 패턴 검출

> **주의**: RPi4는 CSI 포트가 1개. 카메라 2대 사용 시 **Raspberry Pi 5로 업그레이드** 또는 **USB 카메라(UVC) 혼용** 권장

**대안: OpenCV AI Kit-D Lite (OAK-D Lite, ~$150)**
- Stereo 뎁스 카메라 + RGB + 온칩 뉴럴 추론
- 부유물 탐지 딥러닝 모델을 온칩에서 실행 → RPi CPU 부하 제로
- 향후 YOLOv8 기반 부유물 분류 확장 용이
