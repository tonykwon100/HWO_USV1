## 센서별 상세 분석

### 1. DFRobot URM06 (SEN0149 / SEN0150 / SEN0152)

**✅ 추천 1순위 — 화각·거리 최적 매칭**

- 화각 15°로 요구사항 20°에 가장 근접
- RS485 버전(SEN0149)은 다중 센서 연결에 유리 (Modbus RTU)
- 35mm 전선관 규격 PVC 하우징 → 방수 인클로저 추가 필요
- 수면 반사 노이즈 억제를 위해 **UART/RS485 버전** 권장 (소프트웨어 필터링 용이)

**인터페이스 선택 가이드**

| 버전 | 제품번호 | 장점 |
|------|---------|------|
| RS485 | SEN0149 | 다중 센서, 장거리 배선 |
| UART | SEN0150 | 단일 센서, 구현 간단 |
| Analog | SEN0152 | MCU ADC 직결 |
| Pulse | SEN0153 | HC-SR04 핀 호환 |

**주의사항**
- 수면 위 운용 시 수면 반사로 인한 오측거리 발생 가능
- 센서 마운트 각도 5~10° 하향 틸트 권장
- 방수 인클로저(IP65 이상) 별도 제작 필요

---

### 2. Taidacent KS109

**⚠️ 대안 — 좁은 화각이지만 정밀도 높음**

- 화각 ≈10° (요구사항 20°보다 좁음) → 부유물 수집 정밀 위치 파악에 유리할 수 있음
- 온도 보상 내장으로 실외 온도 변화 환경에서 정확도 유지
- I2C 버전: MCU 직결 간단 / RS485 버전: 장거리 배선
- 1mm 분해능 → 정밀 거리 측정 가능

**주의사항**
- 좁은 화각으로 장애물 탐지 커버리지 제한 → 여러 개 배치 필요할 수 있음
- 방수 하우징 별도 필요

---

### 3. MaxBotix MB7389 (참고용)

- IP67 방수 자체 지원으로 방수 처리 불필요
- 단, **최대 5m**로 요구사항 미달 ❌
- MaxBotix의 10m급 제품(HRXL-WR 시리즈)은 별도 확인 필요

## 최종 추천

### 수상 드론 장애물 감지용

**1순위: DFRobot URM06 RS485 (SEN0149)**
- 10m / 15° / RS485 Modbus → 전후좌우 4방향 멀티 센서 구성 가능
- IP65 방수 인클로저 내장 마운트 제작

**2순위: Taidacent KS109-RS485**
- 화각이 좁아 단독 사용 시 커버리지 부족
- 부유물 정밀 위치 파악용 보조 센서로 활용 가능

### 권장 구성 (수상 드론)

```
전방 2x URM06 RS485 (15° × 2 = 30° 커버)
측방 각 1x URM06 RS485
후방 1x URM06 RS485
부유물 정밀 감지 1x KS109 (하향 마운트)
```

---

## 방수 처리 참고

URM06는 자체 방수 미지원 → 아래 방법 중 선택:

1. **방수 인클로저 + 초음파 투과창** (실리콘 씰링)
2. **별도 방수 초음파 변환기 + URM06 회로 분리** (JSN-SR04T 방식 참고)
3. **에폭시 포팅** (센서 교체 불가, 최대 방수)
