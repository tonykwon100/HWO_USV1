## 4.2. 자율운항 알고리즘 개발  

### 1. 목적
- 수조 안에 모든 부유물들을 수거
- 수조 내의 수면 모두를 접근해 부유물을 수거
- 이를 위해 다양한 센서를 사용
- 가장 저렴한 솔루션
### 2. 문제점 검토
- 스케치북에 붓으로 하나의 색으로 색칠을 하는 방법
- 실제로 색칠은 한 방향으로 쭉 하고 어느 정도 덮어서 색칠
- 중요한 정보는 드론의 위치 정보와 이동 정보와 방향
![[Pasted image 20260505175343.png]]
- 사용할 수조 상황
	- x의 길이가 300m, y의 길이가 16m
	- 실내
- 사용 가능한 센서
	- 16 m 측정 가능한 회전 라이더
	- 거리 측정용 저가 TOF 센서
	- 거리 측정용 저가 초음파 센서
	- 드론의 imu 측정
	- 카메라
- 문제점
	- yc의 측정 불가능한 존이 있음
		- 모든 센서들의 측정 범위가 작음
		- yc는 코너를  제외하곤 몰라도 됨
	- mx, my가 부정확함
		- 회전 라이더로 mx는 어느 정도 가능하지만
		- my는 불가능한 존이 있음
		- 드론의 imu도 쉽지 않음
	- 드론에 roll, pirch 등이 존재
		- xc 값이 부정확해짐
	- 센서들의 측정이 이동 중에 이루어짐
		- 측정 오차가 언제니 존재
		- 측정 빈도가 일정 이상이 되어야 함
	- 드론의 위치와 방향을 추정하기 힘듬
		- SLAM 기능을 활용해 위치 정보를 취득하기 힘듬
			- 그냥 큰 직사각형으로 위치를 특정할 특이점이 없음
		- 코너 인식은 되지만 코너를 구분할 수 없음
			- 라이더 센서는 거리만 측정하기 때문에 코너에서의 거리 정보로 그 위치가 어떤 곳인지 구분하지 못함 
	- 수위가 다를 수 있음
		- 수위가 높아서 라이더의 측정 범위를 벗어날 수 있음
	- 장애물 있을 수 있음
		- 장애물이 있으면 장애물 주변를 검색하는 방법에 대해 고민 필요
### 3. 개발 방향
	- 위치와 방향 인식
		- 라이더, 초음파, 카메라의 정보를 퓨전
		- 라이더는 거리 및 2D 형상
		- 초음파는 벽면까지 거리
		- 카메라는 2D Marker
		- Navigator Flight Controller의 정보 획득 (6-DOF IMU, 3-DOF 나침반)

	- 자동 드론 제어
		- 드론 제어 구현
			- Navigator Flight Controller의 제공하는 API를 활용
			- MAVProxy 이용용
		- 필요한 드론 Action using MavLink

### 3. 개발 내역
#### 1) Navigator Driver 
- Mavlink 기반 MAVProxy를 통해 명령과 정보 취득
- 제공 API
	- move : vx, vy
	- rot : deg
	- getinfo : IMU, Compass
#### 2) Lidar Man Driver
- Lidar 센서로부터 raw data를 취득해 주변 벽면이나 장애물 까지의 거리를 측정
- 이 정보를 SLAM 또는 Map 관리에 전달
- 제공 API
	- setConfig
	- getCurLidarData
#### 3) Ultrasonic Driver
- 드론의 4면에 Ultrasonice Sensor를 설치
- 이 Sensor를 저가 MCU에 연결
- 이 정보를 Drone에 전달
- 제공 API
	- getCurUltraData
#### 4) Marker 처리
- Camera로부터 이미지를 획득
- 카메라를 두 대 사용
- AprilTag를 활용해 Coner 또는 벽면의 절대 위치를 얻음
  AprilTag는 Tag 정보와 거리 roll, pitch 등의 정보 제공
- 제공 API
	- getAbsolutePos
#### 5) SLAM 또는 MAP 관리
- Sensor Fusing으로부터 위치 및 이동 정보 저장
- 전체 MAP을 구성
- 전체 History로부터 MAP에서 이동 정보를 관리
- 제공 API
	- getCurCoverRate
	- getMapImg
#### 6) Sensor Fusing
- Sensor fusing으로부터 정제된 Lidar와 초음파센서 정보와 Marker 정보, 그리고 IMU와 Compass로 정보로부터 현재의 추정 위치와 이동 방향과 속도 정보를 생성
- 특히 Marker 정보 획득 시 위치 정보 보정
- 제공 API
	- getCurPosition
	- setCommand
	- setCallback
#### 7) Coordinator 및 Command
- 드론의 상태와 통신 등을 관리
- 드론의 작동 시나리오 관리
	- 시작 위치로 이동
	- 자동적으로 주행
	- Map 관리에서 일정 이상 마무리되면 자동적으로 최종 위치로 이동
