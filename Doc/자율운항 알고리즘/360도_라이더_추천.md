# 360도 회전형 LiDAR 추천 (수상 드론용)

> 요구사항: 측정거리 10m 이상, 스캔속도 2Hz 이상, 360도 회전형

## 추천 모델 비교

| 모델 | 측정거리 | 스캔속도 | 각도분해능 | 가격(USD) | 특이사항 |
|------|----------|----------|------------|-----------|---------|
| **RPLIDAR S2** | 30m | 10Hz | 0.08° | ~$200 | 가성비 최고, ROS2 지원 |
| **RPLIDAR A3** | 25m | 15Hz | 0.33° | ~$380 | 저반사 물체 감지 우수 |
| **YDLiDAR G4** | 16m | 9Hz | 0.26° | ~$100 | 초저가, 수면 부유물 탐지 OK |
| **Hokuyo UST-10LX** | 10m | 25Hz | 0.25° | ~$1,500 | IP67, 산업용, 360°아님(270°) |
| **Leishen LS-01B** | 20m | 10Hz | 0.18° | ~$300 | IP54, 실외 최적화 |

## 핵심 추천

### 1순위: RPLIDAR S2
- 30m / 10Hz → 요구사항 충분히 초과
- ROS2 드라이버 기본 제공, 커뮤니티 활발
- BlueRobotics 계열 SBC(RPi / Jetson)와 바로 연동
- **단점**: IP 등급 없음 → 방수 케이스 별도 필요

### 2순위: Leishen LS-01B (실외 환경 우선이라면)
- IP54로 수면 환경에서 splash 대응 가능
- 한국 대리점 있어 A/S 용이

## 수상 드론 특이사항

> **주의**: 수면 반사광으로 인한 false positive 발생 가능

- 라이더는 **장애물 / 경계 탐지**용으로 사용
- 수면 부유물(기름, 철가루) 탐지는 **카메라 + CV 조합** 권장
- 라이더 단독으로 부유물 식별은 어려움

## 성능/메모리 트레이드오프

- 10Hz × 360° / 0.08° = 포인트 **4,500개/scan**
  - Jetson Nano급이면 실시간 처리 가능
- 15Hz 이상이면 RPi4로는 처리 병목 발생 가능 → **Jetson 권장**
